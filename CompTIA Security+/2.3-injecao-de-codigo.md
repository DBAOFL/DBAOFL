# Injeção de Código
Como o próprio nome diz, é o método onde o atacante inclui seu próprio código no código alvo, e só acontece por conta de programação mal feita, já que a aplicação deveria lidar de forma adequada com as entradas e saídas.

## Injeção SQL
SQL é a linguagem de administração de bancos de dados relacionais mais comum que existe atualmente.
A injeção de SQL (SQLi) acontece quando o atacante adiciona suas próprias consultas e operações em uma aplicação já existente, algo que obviamente essa aplicação não deveria permitir.
