# Infraestrutura de Chave Pública (PKI)
A infraestrutura de chave pública abrange o que será considerado para sua criação e utilização: políticas, procedimentos, hardware, software e pessoas, além de criar, distribuir, administrar, guardar e confiscar certificações digitais.

Um dos pontos mais delicados: é muito sobre confiança. Em certo ponto, precisa-se "confiar" que a autoridade de certificado (CA), seja pessoa ou máquina, é realmente quem diz ser.

## Criptografia Simétrica
Utiliza uma única chave compartilhada, criptografando e descriptografando com a mesma chave. Se a chave vazar, deve-se definir uma nova chave.
Rápido de se usar, mas ruim de escalar.
Ideia: usar criptografia assimétrica para esconder a chave simétrica.

## Criptografia Assimétrica
É a criptografia usada para chaves públicas. Todo usuário tem duas chaves:
- Chave privada: Mantida em segredo.
- Chave pública: Aquela que será compartilhada e todos podem ter.
A chave privada é a única chave que pode descriptografar dados criptografados com a chave pública correspondente.
Ex: Se o usuário A enviar um dado criptografado para o usuário B, a criptografia deve ser feita com a chave pública do usuário B, e quando esse receber o dado, usará a chave privada para descriptografar. Prevenindo que qualquer pessoa que intercepte o dado consiga ler as informações, afinal não terão a chave privada do usuário B, a chave para ler o dado.

## Par de Chaves
Para criar uma nova chave para um usuário, deve-se criar um novo par de chave pública e privada, que serão geradas ao mesmo tempo.
O processo envolve randomizações consideráveis, grandes números primos e muitos cálculos.
