# Blockchain
Tem o objetivo de servir como um registro público das transações, gravando e replicando para todos dentro da blockchain.

Quando uma alteração é realizada, todos recebem uma cópia do registro da transação. Um bloco contendo várias transações é criado, e no último elemento desse bloco, ao invés de uma transação, é adicionado uma hash para o bloco.

O bloco é então adicionado ao final da blockchain e atualizado para todos
