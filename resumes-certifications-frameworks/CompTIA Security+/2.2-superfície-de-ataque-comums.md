# Superfície de Ataque
Vetores de ameaça são os métodos usados pelos agentes maliciosos para ganhar acesso ou infectar o alvo. 

## Vetores
- Mensagens: Links maliciosos em emails ou redirecioados para sites maliciosos;
- Phishing: Links por mensagens para capturar informações de login;
- Imagens: Inserção de informações em imagens;
- Arquivos: PDF contém outros objetos, arquivos comprimidos contém vários arquivos, macros;
- Voz: Vishing (phishing por voz), atrapalhar serviços;
- Hardware: USB com softwares maliciosos;
- Software: Vulnerabilidades para clientes finais ou servidores;
- Sistemas não suportados;
- Internet;
- Portas de serviço;
- Senhas padrão.
