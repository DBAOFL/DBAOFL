# Phishing
É o método usado para conseguir informações sensíveis, como financeiras ou de login, de um usuário final, utilizando principalmente engenharia social.
O atacante pode utilizar de chamadas de voz ou links para conseguir essas informações, se passando pela entidade que o usuário confiaria e daria essas informações.

## Exemplo
- Página de login idêntica ao serviço original;
- Chamada de voz pedindo por transferência financeira;
- Mensagens via redes sociais se passando pelo provedor de serviço ou produto.
