# Cross-site Scripting
Abreviado para XSS, é associado a informações de um site serem compartilhadas com outro, sendo uma das vulnerabilidades de aplicações web mais comuns.
Um caso comum é o atacante fazer com que a vítima clique em um link para um site legítimo que também contém um script malicioso. Ao acessar o site, o script envia as informações de login, cookies, etc, para o atacante.
