# Engano e Pertubação
## Honeypots
Atrair e prender ameaças, normalmente um 'mundo virtual'. Há diversas opções, e se torna uma corrida para descobrir se é real ou não.

## Honeynets
Conjunto de Honeypots, tornando o conjunto mais convincente de ser real.
projecthoneypot.org[https://projecthoneypot.org] para aprofundamento.

## Honeyfiles
Arquivos com informações falsas ou parecem importantes, que funciona como honeypot, mas sendo um arquivo. Enviando um alerta quando o arquivo é acessado.

## Honeytokens
Rastreiam ameaças, seja por um dado na Honeynet. 
API falsas que não dão acesso real, mas sim notificam quando usadas.
Emails falsos.
Outros tipos que permitam rastrear.
