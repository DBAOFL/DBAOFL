# Ofuscação
É o nome dado ao processo de tornar algo menos claro, mais difícil de entender, mas não impossível.

## Steganography
É o processo de esconder informações dentro de outras mais complexas, como uma imagem ou áudio.

## Tokenização
Substitui informações sensíveis por outras não sensíveis, muitas vezes aleatórias.
Ex: Usuário A cadastra o número do cartão de crédito, 1, no celular. O serviço de tokenização associa esse número a um token, 2. Quando o usuário A efetuar uma compra na loja B, a loja receberá que a compra foi feita com o token 2,
