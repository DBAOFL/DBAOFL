# Hashing e Assinaturas Digitais
Uma hash é uma string (texto) que representa um dado, sendo única para um dado específico, funcionando como uma digital. Se o texto ou a hash muda, o outro também mudará.

## Criando Hashes
### SHA256 Hash
256 bits, 64 caracteres hexadecimais.

## Colisão
As hashes devem ser únicas, de forma que diferentes entradas nunca produzam saídas iguais, pois caso aconteça, é uma colisão.

## Hash temperada
Com o "tempero" sendo algum dado aleatório, uma hash temperada é uma hash com essa informação aleatória adicionada para um nível a mais de proteção.
Uma dinâmica é que cada usuário terá um tempero diferente, de forma que mesmo que todos usem a mesma senha, as hashes serão diferentes.
