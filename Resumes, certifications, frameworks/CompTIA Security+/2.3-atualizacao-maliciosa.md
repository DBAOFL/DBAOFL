# Atualização Maliciosa
É uma boa prática sempre manter o sistema operacional e aplicações atualizadas para a versão mais recente. Mas quando se atualiza uma aplicação ou sistema, efetivamente está sendo instalado uma nova aplicação ou sistema. E é possível que nessa atualização exista software malicioso.
Por isso, quando se vai atualizar, é recomendado:
- ter um backup funcional e confiável;
- instalar de fontes confiáveis;
