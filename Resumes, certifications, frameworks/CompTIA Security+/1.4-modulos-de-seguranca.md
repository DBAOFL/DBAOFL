# Módulos de Segurança
## Módulo de Plataforma Confiável (TPM)
Criado para, especificamente, criar fórmulas de criptografia para uma máquina, números aleatórios e chaves. Tendo as próprias chaves gravadas durante a fabricação, e informações de configurações de hardware e armazenamento caso necessário.

## Módulo de Segurança de Hardware (HSM)
Resumidamente, uma versão escalável do TPM. Enquanto esse é para máquinas individuais, o HSM serve para ambientes com várias máquinas, centralizando a criptografia.

## Serviço de Administração de Chaves
Para quando existirem várias chaves para vários serviços, ter um local para administrar todas as chaves pode ser um grande quebra-galho. Muitas das vezes providenciado por um software terceirizado, pode permitir associar chaves a usuários, trocar chaves em intervalos predefinidos e até registrar usos de chaves e outros eventos.
