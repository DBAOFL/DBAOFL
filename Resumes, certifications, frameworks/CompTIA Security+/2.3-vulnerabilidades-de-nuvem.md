# Vulnerabilidades de Núvem
A adoção da nuvem tem sido quase unânime para empresas. Mas isso significa que também há na nuvem informações sensíveis a uma empresa. ~76% das empresas não usam autenticação de múltiplos fatores (MFA) para usuários, o que está longe de ser sequer o mínimo para segurança.

## Ataque
### o serviço
Pelo serviço ser centralizado na nuvem, se houver um ataque a esse servidor, não seria apenas um usuário que seria afetado, mas sim todos que utilizam, a menos que o ataque seja especificado para apenas certos usuários.

### a aplicação
Como aplicações web são mais propensas a ter mais opções de ataque e vulnerabilidades, é um alvo valioso para os atacantes. Em um mesmo site pode-se tentar: XSS, SQLi, overflow, etc.
