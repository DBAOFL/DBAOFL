# Segmentação e Controle de Acesso
A segmentação de uma rede pode ser física, lógica ou virtual. 

Como pode afetar o desempenho de algumas aplicações a segmentação extensiva, é comum de haver uma segmentação apenas para essas aplicações de alta demanda, assim permitindo desempenho total.
