# Segmentação e Controle de Acesso
A segmentação de uma rede pode ser física, lógica ou virtual. 

Como pode afetar o desempenho de algumas aplicações a segmentação extensiva, é comum de haver uma segmentação apenas para essas aplicações de alta demanda, assim permitindo desempenho total.

` Usuário -> Aplicação -> Servidores/Sistemas/Ativos `

## Lista de controle de acesso (ACL)
Forma prática de controlar tráfico por grupos de categorias: IP de origem, IP de destino, número da porta, horário do dia, aplicação, etc., ou até por dispositivos.

### White List e Black List
Duas formas de criar permissões
- White List: **Apenas** o que estiver nessa lista é **permitido**. **Tudo** que *não estiver*, é **proibido**.
- Black List: **Apenas** o que estiver nessa lista **não é permitido**. **Tudo** que *não estiver*, é **permitido**.
