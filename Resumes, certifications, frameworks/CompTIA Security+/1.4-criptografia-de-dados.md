# Criptografia de Dados
Criptografia é usada para proteger dados, podendo proteger um armazenamento como um todo, uma seção desse ou apenas um dado.

Também pode-se criptografar dados entre redes, por meio de uma aplicação (e.g. HTTPS) ou uma rede virtual privada (VPN), por exemplo.

## Algoritmos
Existem diversas formas de criptografar dados, mas tanto para quem está criptografando, quanto quem irá descriptografar, devem concordar em qual algoritmo irão utilizar. Esses detalhes são comumente escondidos do usuário final.
