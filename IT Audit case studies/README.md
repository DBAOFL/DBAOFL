# Estudos de Caso

Este repositório tem como objetivo armazenar minhas documentações sobre estudos de caso fictícios e reais. Para se redirecionar para cada um desses repositórios, respectivamente, segue um link rápido: [Fictícios](https://github.com/DBAOFL/estudos-de-caso/tree/master/ficticios) & [reais](https://github.com/DBAOFL/estudos-de-caso/tree/master/reais)

---

## O estudo
Será utilizado o seguinte modelo em todos os estudos:

### Divisões
- Resumo executivo;
- Sobre a empresa;
- Sobre o pré-caso;
- Sobre o caso;
- Sobre o pós-caso.

### Subdivisões
<!--Tabela-->
| Divisão          | Subdivisão |
|:----------------:|------------|
| Resumo executivo | - Gravidade geral;<br>- O que aconteceu, em 3-4 linhas. | 
| Sobre a empresa  | - Dados da empresa;<br>- Resumo geral. |
| Objetivo e escopo | - O que foi analisado;<br>- O que ficou fora;<br>- Framework/norma de referência. |
| Sobre o pré-caso | - Quem percebeu o incidente;<br>- O que aconteceu antes do incidente;<br>- Por que não foi detido;<br>- Sobre o malfeitor. |
| Sobre o caso     | - Metodologia;<br>- O que aconteceu;<br>- Como passou pelas medidas de segurança;<br>- Desenvolvimento;<br>- Como se desenvolveu;<br>- O que foi feito para contenção ou afins;<br>- Como foi detido (caso tenha sido);<br>- Quais ativos foram comprometidos;<br>- Cadeia de custódia/evidência;<br>- Classificação de severidade dos achados. |
| Sobre o pós-caso | - Reparação;<br>- Novas contra-medidas;<br>- O que poderia ter sido feito.<br>
